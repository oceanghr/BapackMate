# BapackMate

BapackMate adalah website yang dirancang untuk membantu pengguna mempersiapkan perjalanan backpacking. Website ini menyediakan informasi mengenai destinasi wisata, perencanaan anggaran, dan tips yang dapat membantu pengguna mempersiapkan perjalanan secara lebih terstruktur.

## Deskripsi Project

BapackMate merupakan hasil redesign dari repository latihan pemrograman web.

Konsep website berfokus pada kebutuhan pengguna yang ingin merencanakan perjalanan, mencari destinasi, mengatur anggaran, dan memperoleh tips backpacking.

## Fitur Website

Website BapackMate memiliki beberapa bagian utama:

1. **Home**
   - Menampilkan pengenalan website.
   - Menampilkan informasi singkat mengenai BapackMate.

2. **Destination**
   - Menampilkan informasi mengenai destinasi perjalanan.
   - Membantu pengguna menemukan inspirasi tempat wisata.

3. **Budgeting**
   - Menampilkan kategori pengeluaran perjalanan.
   - Menyediakan contoh estimasi biaya backpacking.
   - Menampilkan tips mengatur anggaran perjalanan.

4. **Tips**
   - Menyediakan informasi dan tips untuk persiapan backpacking.
